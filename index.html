วิธีนำเว็บนี้ไปรันฟรีบน GitHub Pages

ทำตาม 4 ขั้นตอนนี้เพื่อเผยแพร่เว็บไซต์ของคุณให้คนอื่นเข้าใช้งานได้ทั่วโลก

1

สร้าง Repository บน GitHub

ล็อกอินเข้า GitHub.com แล้วกดปุ่ม New Repository ตั้งชื่อ เช่น my-ai-kitchen แล้วเลือกสถานะเป็น Public

2

อัปโหลดไฟล์ index.html

คัดลอกโค้ดทั้งหมดในหน้านี้ บันทึกลงในคอมพิวเตอร์ของคุณในชื่อไฟล์ว่า index.html จากนั้นกด uploading an existing file บน GitHub เพื่ออัปโหลดไฟล์

3

เปิดใช้งาน GitHub Pages

ไปที่เมนู Settings ➔ เลือกหัวข้อ Pages ด้านซ้ายมือ ➔ ในส่วน Branch ให้เลือกเป็น main (หรือ master) แล้วกด Save

เสร็จสิ้น! ได้รับลิงก์เว็บไซต์

รอประมาณ 1-2 นาที คุณจะได้ลิงก์เว็บไซต์ เช่น https://yourname.github.io/my-ai-kitchen/ สำหรับเปิดใช้งานทันที!
